Review before you run / 执行前先审阅

Category is only a discovery aid. Open the pinned source, check the license and referenced resources, prefer a reviewed package when available, and start with a read-only task in a recoverable workspace.
类别只是发现辅助。打开固定来源，检查许可证和引用资源；有精选包时优先选择，并在可恢复工作区中先执行只读任务。

For an installable package, verify the ZIP with SHA256SUMS and upload the original archive through WorkBuddy's Skills import flow.
安装精选包时，先用 SHA256SUMS 校验 ZIP，再通过 WorkBuddy 的 Skills 导入流程上传原始压缩包。
