# Contributing

Thanks for improving SandBase for WorkBuddy.

1. Keep `SKILL.md` concise and move conditional detail into `references/`.
2. Base tool behavior on current SandBase schemas and WorkBuddy documentation.
3. Do not commit secrets, private customer data, copied proprietary prompts, or generated API responses containing personal data.
4. Run `python3 scripts/validate_skill.py` before opening a pull request.
5. Describe the real user request or failure that motivated an instruction change.

Bug reports should include the WorkBuddy version, the requested capability, the failure message with secrets removed, and the expected behavior.
