## Official product documentation

- [Quickstart](https://www.workbuddy.ai/docs/workbuddy/Quickstart) — platform setup and first use.
- [WorkBuddy overview](https://www.workbuddy.ai/docs/zh/) — official product capabilities, scenarios, and recommended reading order.
- [Agents quickstart](https://www.workbuddy.ai/docs/zh/ide/User-guide/Agent-Mode/Quickstart) — official task creation, task lists, parallel work, conversations, and result-panel orientation.
- [Memory](https://www.workbuddy.ai/docs/zh/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Memory) — manage conversation-derived preferences, review generated memories, and control what WorkBuddy remembers.
- [Mac Installation Guide](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Mac-Guide) — official macOS requirements, universal DMG installation, first-launch security prompt, sign-in, and requested system permissions.
- [Windows Installation Guide](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide) — official Windows requirements, x64/ARM64 installer steps, SmartScreen handling, sign-in, and first-launch troubleshooting.
- [Tips & Tricks](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Efficient-Tips) — practical guidance for clearer prompts, references, iteration, workspaces, and Skills.
- [FAQ](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/FQA) — common questions about WorkBuddy, Skill updates, permissions, and connectors.
- [Release Notes](https://www.workbuddy.ai/docs/zh/ide/release-notes/release-notes) — current product changes and fixes, including SkillHub, plugin, connector, model, and platform updates; check this before relying on a UI or installation behavior.
- [Privacy Policy](https://www.workbuddy.ai/document/privacy-policy) — official product data-handling and privacy disclosures to review before using sensitive inputs or connectors.
- [Service Agreement](https://www.workbuddy.ai/document/term) and [Acceptable Use Policy](https://www.workbuddy.ai/document/acceptable-use-policy) — official account, service-use, permitted-use, and responsibility terms.
- [Permission Modes](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Permission-Modes) — official guidance for workspace scope and operation permissions before allowing a Skill or connector to act.
- [Task Bar](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar) — choose a task workspace, model, installed Skills, connectors, and permission mode before execution.
- [Large repositories and monorepos](https://www.workbuddy.ai/docs/cli/large-codebases) — official guidance for directory-level instructions, focused worktrees, per-package configuration, and keeping agent context scoped.
- [Assistant Remote Control](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Assistant) — configure supported messaging integrations for sending tasks and receiving results; WorkBuddy must remain running, and each platform has its own account and permission setup.
- [DingTalk integration](https://www.workbuddy.ai/docs/zh/workbuddy/Platform-Integration/Dingtalk-Guide) and [Yuanbao integration](https://www.workbuddy.ai/docs/zh/workbuddy/Platform-Integration/YuanBaoPai-Guide) — official platform-specific setup guides for Assistant Remote Control; review the required admin roles and credentials before configuration.
- [Model Configuration](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) — configure Auto Mode, provider presets, custom models, and local Ollama connections.
- [Create Skills](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Create-Skills) — authoring Skills.
- [MCP guide](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/MCP-Guide) — MCP concepts and configuration.
- [Open Platform Connector guide](https://open.workbuddy.cn/en/docs/connector) — recommends MCP + Skill for network APIs, limits CLI + Skill to mature cross-platform CLIs, and documents runtime, credentials, OAuth, and permissions.
- [Open API reference](https://open.workbuddy.cn/en/docs/openapi) — official API and OAuth reference for WorkBuddy integrations.
- [Third-Party App guide](https://open.workbuddy.cn/en/docs/third-party-app) — OAuth 2.1 authorization, app registration, callback configuration, and the boundary between user approval and Open API access.
- [GitHub CLI `gh skill` manual](https://cli.github.com/manual/gh_skill) — preview commands for searching, previewing, installing, and updating Agent Skills.
- [Agent Skills specification](https://agentskills.io/specification) — vendor-neutral `SKILL.md` format, naming rules, optional directories, and portability guidance.
- [Automation guide](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide) — automation workflows.
- [Skill Marketplace](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market) and [Explore](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Explore) — built-in capabilities.
- [Open Platform Skill guide](https://open.workbuddy.cn/en/docs/skill) — official Marketplace placement, ZIP troubleshooting, frontmatter fields, and sub-resource layout.
- [Open Platform overview](https://open.workbuddy.cn/en/docs/what-is-open-platform) — the full onboarding, development, test, review, publishing, and maintenance path.
- [Open Platform onboarding](https://open.workbuddy.cn/en/docs/onboarding) — developer and enterprise verification preparation before publishing ecosystem assets.
- [Buddy App guide](https://open.workbuddy.cn/en/docs/buddy-app) — package industry workflows into a ready-to-use WorkBuddy workspace with Skills, connectors, and preview testing.
- [Expert guide](https://open.workbuddy.cn/en/docs/expert) and [Expert Team guide](https://open.workbuddy.cn/en/docs/expert-team) — configure marketplace experts, teams, agents, Skills, prompts, and connector dependencies.

## Learning and evaluation

- [WorkBuddyGuide](https://github.com/AlephAITech/WorkBuddyGuide) — task-oriented community walkthrough; its [online reading site](https://workbuddy.homes) is convenient for browsing.
- [WorkBuddy account migration](https://github.com/xiaoliuzhuan666/workbuddy-account-migrate) — MIT-licensed cross-platform recovery reference for conversations, memory, and connectors after an account switch; start with diagnostic mode and verify backup, rollback, and target-account details before changing local databases.
- [Self-media compliance review](https://github.com/JuneYaooo/self-media-compliance-review) — MIT-licensed WorkBuddy-compatible pre-publication review workflow for short video, cover, copy, commerce claims, and platform risk; its default evidence search is local, while optional real-time channels can require credentials, network access, and paid quota.
- [QianLV UI Skill](https://github.com/CodeGanHaoZ/gks-QianLV-uiSkill) — MIT-licensed WorkBuddy-compatible mobile UI design reference with theme tokens, component patterns, cross-platform notes, and a scaffold script; inspect its bundled assets and scripts before reuse.
- [CodeDrobe Skills](https://github.com/CodeDrobe/skills) — Apache-2.0 WorkBuddy-compatible theme workflow for creating, applying, verifying, repairing, and restoring reversible desktop themes; it uses a separate runtime and may require CDP, so review app scope and restart approvals before use.
- [CodeDrobe Core](https://github.com/CodeDrobe/core) — Apache-2.0 runtime behind the CodeDrobe WorkBuddy theme workflow, with pinned `npx`/`bunx` commands, app detection, reversible CDP injection, and verification; keep the runtime version pinned and review restart or app-path permissions.
- [Ontology Driven Dev](https://github.com/sharptoolbox/ontology-driven-dev) — MIT-licensed WorkBuddy-compatible reference for requirements exploration, ontology modeling, and application construction with human confirmation gates; it bundles a substantial runtime and examples, so inspect dependencies, local data, and model/API configuration before running it.
- [WorkBuddy AppBuilder Skill](https://github.com/sharptoolbox/WorkBuddy-AppBuilderSkill) — MIT-licensed focused reference for requirements discovery, domain modeling, and app generation; review its generated-artifact and model/API boundaries before adapting it.
- [Image Story Video Wizard](https://github.com/aaronyi97/image-story-video-wizard) — MIT-licensed confirmation-gated workflow for audio-first image-story video production across Codex and WorkBuddy; inspect media paths, external tools, and approval steps before use.
- [WorkBuddy Guide](https://github.com/Neo5093/workbuddy-guide) — MIT-licensed community reference Skill with a beginner path, connector troubleshooting, automation patterns, model guidance, FAQs, and environment diagnostics; inspect its scripts and version before adapting anything.
- [WorkBuddy Practice Guide](https://github.com/opcspace/WorkBuddy-Guide) — Chinese community knowledge base for secure installation, first tasks, permissions, troubleshooting, connectors, remote assistance, and acceptance-oriented workflows; verify its freshness and license before reuse.
- [WorkBuddy Starter](https://github.com/sunyet-01/WorkBuddy-Starter) — MIT-licensed beginner-oriented collection organized around onboarding, Skills, scenarios, and examples.
- [QA Testing Guide](https://github.com/genapohub/qa-testing-guide) — MIT-licensed WorkBuddy-compatible Skill reference for test strategy, automation, performance testing, and defect workflows; inspect its files before adapting.
- [WeChat Article Skills](https://github.com/aiworkskills/wechat-article-skills) — Apache-2.0 WorkBuddy-compatible Chinese workflow collection for topic selection, writing, review, formatting, images, and draft publishing; each stage pauses for confirmation, but review API keys, local files, and publishing permissions before use.
- [Agentic Awesome Skills](https://github.com/sickn33/agentic-awesome-skills) — MIT-licensed local catalog and control plane for discovering, selecting, and validating agentic Skills; use it as a research reference, not an automatic installer.
- [Awesome Agent Skills](https://github.com/linny006/awesome-agent-skills) — auto-updated cross-agent discovery index with quality and maintenance signals; the repository currently declares no license, so use it only for navigation and inspect each upstream source independently.
- [kendex](https://github.com/vanillagreencom/kendex) — MIT-licensed cross-harness manager for Skills, agents, hooks, and extensions, with preview-before-apply and source tracking; it is a separate tool, not a WorkBuddy package, so review its filesystem scope before using it to manage local installations.
- [semlinker/awesome-workbuddy](https://github.com/semlinker/awesome-workbuddy) — CC0 resource navigation for WorkBuddy tutorials, prompts, Skills, MCP, and practical scenarios; verify each linked project's current terms.
- [AI Coding Guide 中文教程](https://github.com/KimYx0207/AI-Coding-Guide-Zh) — broad Chinese tutorial covering WorkBuddy and adjacent agent workflows.
- [E-commerce visual copywriting Skill](https://github.com/feichanggege/ecommerce-visual-copywriting-skill) — an MIT-licensed WorkBuddy-compatible e-commerce visual-copy workflow with a large community footprint; inspect bundled assets and scripts before reuse.
- [agency-agents-zh](https://github.com/jnMetaCode/agency-agents-zh) — an MIT-licensed Chinese collection of reusable expert roles across engineering, design, marketing, finance, and other workflows; inspect attribution and bundled assets before reuse.
- [WorkBuddy Usage Status](https://github.com/clancy-feng/workbuddy-usage-status) — MIT-licensed, offline-first usage dashboard for local token, credit, model-efficiency, and error analysis; inspect its local-data and optional credential boundaries before use.
- [Agent Analytics Report](https://github.com/Elisabeth15501/agent-analytics-report) — MIT-licensed WorkBuddy usage-analysis tool for token, model-cost, and anomaly reports; it reads local traces, databases, and usage logs, so confirm the privacy boundary and share only redacted reports.
- [WorkBuddy Codex Hub MCP](https://github.com/somo-ui/workbuddy-codex-hub-mcp) — MIT-licensed early local MCP collaboration reference using a SQLite task pool for WorkBuddy/Codex claiming, submission, and independent review; its README explicitly notes the lack of production hardening, concurrent-write locking, and hosted execution, so review code and deployment boundaries before reuse.
- [WorkBuddy Chat Manager](https://github.com/sutupikk-cyber/workbuddy-chat-manager) — MIT-licensed local chat-recovery/cleanup reference touching `workbuddy.db`, JSONL sessions, and a trash directory; it documents backups and confirmation, but deletion remains high risk—back up first, verify account and path, and manually confirm targets.
- [MnemoPort](https://github.com/muzishuiji/mnemoport) — MIT-licensed local AI-asset portability tool for moving file-backed instructions, Skills, prompts, and credential-free MCP definitions between WorkBuddy and other agent tools; auto-memory, account data, and plugins are not migrated automatically, so confirm target paths and make a backup first.
- [WorkBuddy cross-device sync reference](https://github.com/jamesting-eng/workbuddy-skills) — MIT-licensed Windows/WPS-cloud sync and handoff workflow; it touches workspace, identity, and memory-related files, so do not treat it as a risk-free database synchronizer—back up first and review scripts, paths, and credential boundaries before reuse.
- [markitdown-skill](https://github.com/stwhwing/markitdown-skill) — MIT-licensed document and web-page-to-Markdown workflow for WorkBuddy, with a default SSRF guard and optional external capabilities disabled by default; inspect scripts and permissions before adapting.
- [Learn WorkBuddy](https://github.com/adongwanai/learn-workbuddy) — MIT clean-room course on Agent harness architecture.
- [WorkBuddy Harness v2](https://github.com/zhuang-HE/workbuddy-harness) — architecture and evaluation reference covering nine Agent infrastructure dimensions, a Hook/Eval runtime, safety guardian, and benchmark cases; the README displays an MIT badge but the repository has no formal `LICENSE` file, so do not treat it as redistribution permission.
- [yinqd3/workbuddy-skills](https://github.com/yinqd3/workbuddy-skills) — MIT-licensed community collection with academic research, frontend slides, and tool-call workflows; use it as a source to inspect, not an automatic trust signal.
- [Huawei Cloud DevKit](https://github.com/huaweicloud/huaweicloud-devkit) — Apache-2.0 official Huawei Cloud toolkit with explicit WorkBuddy support, Skills, MCP, CLI, and pre-execution safety checks; review credentials and cloud-side effects before use.
- [CloudBase AI Toolkit](https://github.com/TencentCloudBase/CloudBase-AI-Toolkit) — Tencent Cloud’s official backend toolkit with explicit WorkBuddy support, Skills, MCP, authentication, database, storage, functions, and deployment workflows; review the target environment and confirm sensitive operations before execution.
- [Qwen-MM-Plugins](https://github.com/QwenLM/Qwen-MM-Plugins) — Apache-2.0 multimodal plugin collection with separate Skill and optional MCP capabilities; inspect model/API keys, local runtimes, and media-data boundaries before enabling a capability.
- [SkillDeck](https://github.com/crossoverJie/SkillDeck) — MIT-licensed macOS manager with explicit WorkBuddy/CodeBuddy support for browsing, importing, updating, and assigning Skills; review its filesystem and symlink permissions before use.
- [skill-manager](https://github.com/GrubbyLee/skill-manager) — MIT-licensed, zero-dependency local Skill/MCP governance CLI with WorkBuddy directory support for scanning, recommendations, duplicate detection, audits, and dry-run lifecycle plans; it is read-only by default, but review any requested write before running it.
- [Skills Hub](https://github.com/qufei1993/skills-hub) — MIT-licensed cross-platform Skill manager that can organize and sync Skills to multiple agent directories, including `~/.workbuddy/skills`; review scanned paths, local settings, and tokens before use.
- [oh-my-workbuddy](https://github.com/mrzhangguoguo/oh-my-workbuddy) — MIT-licensed bilingual WorkBuddy port with catalog-driven workflow conventions.
- [WorkBuddy Harness blue book](https://github.com/zjp1997720/zhijian-ai-bluebook-workbuddy-harness) — evidence-bounded deep dive into local files, prompt assembly, extensions, and safety boundaries; its [online edition](https://zjp1997720.github.io/zhijian-ai-bluebook-workbuddy-harness/) is convenient for browsing. Research reference without a repository license declaration.

- [Community Awesome WorkBuddy](https://github.com/staruhub/awesome-workbuddy) — another bilingual index of official resources, workflows, tutorials, and comparisons; use as navigation, not as a trust or license decision.
- [WorkBuddy Skill Groups](https://github.com/darker2016/workbuddy-skill-groups) — an open collection of multi-agent team workflows across engineering, research, marketing, design, legal, finance, and data; inspect each folder's attribution and license before reuse.
